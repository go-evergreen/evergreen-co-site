# Evergreen Co — public site

A public answers page for Evergreen Co. Standalone on purpose: **First Seeds is not modified.** Sister to The Fresh Grove site — this one shows the Evergreen hub (Sprout, Calendar, Learn, Resources), not Grove.

People who want in connect with whoever sent them this page.

Live: [https://go-evergreen.github.io/evergreen-co-site/](https://go-evergreen.github.io/evergreen-co-site/)

## Preview

```bash
cd "/Users/tayrourke/Desktop/evergreen-co-site"
python3 serve.py
```

Then open [http://localhost:8766](http://localhost:8766).

## What’s here

Team page + a **tappable dummy hub** (Sprout, Calendar, Learn, Resources). Dummy names only. No Leads tab, no Grow Your Grove — those are Fresh Grove. First Seeds is untouched.
